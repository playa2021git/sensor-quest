# センサークイズ — micro:bit・センサ・AIを学ぼう

中学校技術科「計測・制御」「技術による問題解決」の導入教材。タイトルから基礎編と応用編を選べます。基礎編は○×10問、応用編は従来の4択10問（前半は身近な技術、後半は再発明）です。取得できる情報と限界を比べます。

## 起動

ビルド、データベース、ログイン、APIキーは不要。リポジトリ内で `npm start`、または `python3 -m http.server 4173` を実行し、ローカルHTTPで開きます。ES Modulesを使うためfile://での直接起動には対応しません。外部サービスへの実行時接続はありません。

GitHub Pagesはmain / (root)を使用できます。資源は相対パスで読み込みます。この変更ではPages設定やmainへの自動マージは行いません。

## 基礎編と解放条件

基礎編は全10問・時間制限なし。左右キー（←は○、→は×）、クリック、Tab＋Enterで回答します。毎問すぐに解説を表示し、最後に正解数と全問の復習を表示します。7問以上正解すると応用編を解放します。6問以下でも何度でも再挑戦できます。一度解放した応用編は、後の挑戦が不合格でも解放を維持します。

最高記録と解放状態はこのブラウザのlocalStorageに保存します。保存が使えない環境では、同じページを開いている間だけ進捗を保持します。タイトルの「進捗をリセット」で確認後に記録を消し、応用編を未解放に戻せます。共有端末では利用者交代時にリセットしてください。ログインや個人別の記録管理、厳密なアクセス制御ではありません。

基礎編の問題はsrc/basics.js、画面と進捗はsrc/basic-mode.jsにあります。PIRの検知範囲は模式図であり、一律の角度・距離を保証しません。micro:bitの時計問題は、現在時刻を電源断後も保持する電池付きRTCユニットが標準搭載されない点を扱い、経過時間の計測と区別します。センサ画像は生成した教材用イメージです。生徒の氏名・学級・原文は保存していません。

## 応用編の操作と採点

- 1366×768を対象。クリック、A〜Dキー、Tab＋Enterで回答します。選択肢は毎回シャッフルし、IDで採点します。
- 最適2点、実現可能1点、不適切・時間切れ0点。全10問・20点満点。第1問は物理ボタンが最適、タッチロゴとAI音認識は実現可能です。第9問は実現可能な方法が2つあります。
- 1問30秒。設定で時間制限をなくせます。時間設定は次問から適用し、ダイアログ中も時計は進みます。
- 第6問前にステージ移行画面があります。移行中は時間を進めません。
- 各問の解説で4つすべての取得情報・長所・限界・判定理由を比較できます。比較タブは左右矢印・Home・Endキーに対応します。
- 結果から全問復習、最適でなかった問題の復習、再挑戦ができます。
- ランクはS 18〜20 / A 15〜17 / B 11〜14 / C 7〜10 / D 0〜6点。得点は理解の参考であり学習評価そのものではありません。
- 音は初期ミュート。音量、全画面表示、演出OFFに対応し、OSのreduced-motionも優先します。

回答履歴は実行中のメモリだけに保持し、再読み込みで消えます。設定と基礎編の最高記録をlocalStorageに保存し、保存不可でも動きます。個人情報収集、回答送信、アクセス解析はなく、ゲーム自体がカメラ・マイクの権限やAIモデルの実行を要求することもありません。

## テスト

Node.js 20以上、Python 3、Chromiumを使用します。

```sh
npm ci
npm test
npm run test:browser
```

Chromiumの既定パスは/usr/bin/chromium。別の場所では `CHROMIUM_PATH=/path/to/chromium npm run test:browser` を使います。

単体テスト9件で全40選択肢の採点、問題構造、冷水機のタッチ入力の1点判定、時間切れ、ランク境界、シャッフル、デバイスIDと画像の存在を検証します。ブラウザ検証では基礎編の6問・7問の境界、満点、解放維持、再読み込み、リセット、保存拒否環境での一時解放を確認します。続けて1366×768で応用編全10問を完走し、4択、Eキーの無効化、二重回答防止、全40選択肢の復習、物理ボタンでの満点とタッチ入力の1点判定、混合採点、代替方法、タイマー、演出設定、全画面、画像欠損時の動作、JS例外と主要領域のはみ出しを確認します。テスト用HTTPは4175番で起動・終了し、結果JSONと画像は無視対象のwork/へ出力します。

学校の管理端末やGitHub Pages本番での確認、実機センサの性能評価は別途必要です。

## ライセンス

[LICENSE](LICENSE)のMITライセンスを維持します。生成画像は架空の状況図であり、実物の配線や安全性を示す写真ではありません。

基礎編の解説は本文26px・補足21pxに拡大し、正解時は緑の光る枠と喜ぶ猫、誤答時は赤い背景・動く黄黒の警告枠・残念がる猫を表示します。長い解説は中央の領域内でスクロールでき、次へ進むボタンは常に表示します。演出OFF・OSのreduced-motion時には動きを止め、色と判定表示は残します。

正解後の解説は金・銀・プラチナのゆっくり流れる光と太いメタリック枠で継続して強調します。基礎編の結果は大きな得点、クリア／再挑戦メダル、猫、光の帯と金銀の紙吹雪で表示します。応用編の結果も同じ配色と演出を使用します。演出OFF時は動きを止めて読みやすい静止配色を保ちます。

画面名は「センサークイズ」です。木工室の作業台でmicro:bit・センサ・AIを学ぶ配色と背景を使用し、操作や補足の文字を原則18px以上にしています。旧リポジトリ名・既存URL・ブラウザ内の進捗保存キーは保持しています。リポジトリ改名時はGitのremote、GitHub Pagesの公開URL、配布リンクの更新を別途確認してください。

案内猫はタイトルと同じ実写風の6ポーズに統一しています。問題画面・解説・結果の猫を拡大し、応用編は選択肢の隣、解説は専用の左欄に配置します。タイトル文字は72px、各画面の見出しロゴは32pxです。

基礎編第1問は、真正面の一本の線だけを検知するという説明図の正誤を問います。回答前は正誤を明示せず、解説で誤った図と広がる検知範囲を比較します。応用編の結果画面には、基礎編に加えて6か所の花火・スポットライト・大きな紙吹雪を表示します。演出OFFとreduced-motionでは停止します。

## 画面の動き

基礎編は緑の太枠、応用編は紫と金の二重枠で区別します。文字のウェーブ、カードのライトスイープ・ホバー浮上、猫の登場と浮遊、選択肢の順次登場、正解時の放射バーストを加えています。問題文・選択肢・採点・解放条件は変更していません。

[Motion Prompt](https://showheyohtaki.github.io/motion-prompt/)（MIT、© 2026 Shohei Ohtaki）の #081 Hover lift、#022 Light sweep、#130 Wave text、#003 Burst を参考・移植しています。CSSのイージングは近似、文字の上下距離は文字サイズに比例、バーストは背景・ハートを省いた透明レイヤーにしています。演出OFFとOSの「動きを減らす」で停止します。

解説画面では、追加で次のMotion Promptを使っています（MIT、出典は各実装ファイル）。

- [#001 Pop-in](https://showheyohtaki.github.io/motion-prompt/#001)：次へ進むボタン。ばねの式で1度登場して保持。
- [#005 Mask reveal](https://showheyohtaki.github.io/motion-prompt/#005)：不正解／最適以外の解説を上下のマスクから表示。0.35秒・0.55秒から開始し、最後は表示を保持。
- [#008 Kinetic typography](https://showheyohtaki.github.io/motion-prompt/#008)：判定文字に「ドン！」の拡大・着地を適用。
- [#012 Shape morph](https://showheyohtaki.github.io/motion-prompt/#012)：解説の猫の下で丸・四角・星・ハートが変形。元の輪郭240点・4.7秒周期を使用し、背景のみ透明化。
- [#016 Parallax](https://showheyohtaki.github.io/motion-prompt/#016)：タイトルの背景・写真・猫を異なる奥行き係数で動かす。元の4.7秒の正弦波を1往復して停止。
- [#020 Zoom through](https://showheyohtaki.github.io/motion-prompt/#020)：正解／最適の解説へ丸い穴を通って拡大。元の指数倍率と1.65秒の加減速を使用。ZOOMの文字を正解表示へ、穴の向こうを実際の解説DOMへ置換。

第1問の解説は猫を100×150pxに縮めて本文側を広げ、1366×768で説明と2つの図をスクロールせず読めます。`npm run test:motion` はこの収まり、両モードの切り替え、画面移動後の後片付け、演出OFF・reduced-motionを確認します。
