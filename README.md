# SENSOR QUEST — 最適なセンサを選べ！

中学校技術科「計測・制御」「技術による問題解決」の導入教材。前半5問は身近な技術、後半5問は困りごとを解決する再発明です。全10問・各4択で、取得できる情報と限界を比べます。

## 起動

ビルド、データベース、ログイン、APIキーは不要。リポジトリ内で `npm start`、または `python3 -m http.server 4173` を実行し、ローカルHTTPで開きます。ES Modulesを使うためfile://での直接起動には対応しません。外部サービスへの実行時接続はありません。

GitHub Pagesはmain / (root)を使用できます。資源は相対パスで読み込みます。この変更ではPages設定やmainへの自動マージは行いません。

## 操作と採点

- 1366×768を対象。クリック、A〜Dキー、Tab＋Enterで回答します。選択肢は毎回シャッフルし、IDで採点します。
- 最適2点、実現可能1点、不適切・時間切れ0点。全10問・20点満点。第1問は物理ボタンが最適、タッチロゴとAI音認識は実現可能です。第9問は実現可能な方法が2つあります。
- 1問30秒。設定で時間制限をなくせます。時間設定は次問から適用し、ダイアログ中も時計は進みます。
- 第6問前にステージ移行画面があります。移行中は時間を進めません。
- 各問の解説で4つすべての取得情報・長所・限界・判定理由を比較できます。比較タブは左右矢印・Home・Endキーに対応します。
- 結果から全問復習、最適でなかった問題の復習、再挑戦ができます。
- ランクはS 18〜20 / A 15〜17 / B 11〜14 / C 7〜10 / D 0〜6点。得点は理解の参考であり学習評価そのものではありません。
- 音は初期ミュート。音量、全画面表示、演出OFFに対応し、OSのreduced-motionも優先します。

回答履歴は実行中のメモリだけに保持し、再読み込みで消えます。設定のみlocalStorageに保存し、保存不可でも動きます。個人情報収集、回答送信、アクセス解析はなく、ゲーム自体がカメラ・マイクの権限やAIモデルの実行を要求することもありません。

## 問題構成

| 問 | テーマ | 最適な入力 |
|---|---|---|
| 1 | 学校の冷水機 | A・Bボタン |
| 2 | 車の駐車支援 | 超音波距離センサ |
| 3 | 学校の階段の自動ライト | 明るさセンサ＋人感センサ |
| 4 | スマホの画面の自動回転 | 加速度センサ |
| 5 | スマートウォッチの歩数計 | 加速度センサ |
| 6 | 図書館の静かにお知らせ | 内蔵マイク（音量） |
| 7 | 老猫のごはんを守ろう | AIカメラ（画像認識） |
| 8 | 玄関の鍵、かけたかな？ | AIカメラ（つまみの向きを分類） |
| 9 | 勉強中のスマホ注意係 | AIカメラ（手に取る様子を分類） |
| 10 | 置き配の持ち去りお知らせ | AIカメラ＋重量センサ |

授業用デバイスガイドと入力・出力IDを合わせています。AIはChromebook等で実行しmicro:bitへ結果を渡す構想であり、micro:bit単体でTeachable Machineを動かすものではありません。鍵や置き配の問題は状態・人物分類を検討する試作で、防犯性能や確実な本人認証を保証しません。全問題と判定理由は[CONTENT_REVIEW.md](CONTENT_REVIEW.md)に記載します。

## ファイルと画像

- `src/questions.js`：全10問と40選択肢。
- `src/app.js`：画面・状態遷移・操作・時計。
- `src/engine.js`：DOM非依存の採点・集計・シャッフル。
- `src/encyclopedia.js`：19種類の入出力デバイス図鑑。
- `src/assets.js`：画像シートと差し替え設定。
- `src/style.css`：レイアウト・2ステージの配色・演出。

問題画像は困っている場面を中心にした生成画像です。冷水機も実写風の生成画像で、実在する販売商品の写真ではありません。駐車支援の画像は従来のものを保持し、案内猫は黒い作業服と安全ヘルメットを着けた、大きなゆるい漫画調のキャラクターに更新しています。画像配置と差し替えは[IMAGE_ASSETS.md](IMAGE_ASSETS.md)を参照してください。

## テスト

Node.js 20以上、Python 3、Chromiumを使用します。

```sh
npm ci
npm test
npm run test:browser
```

Chromiumの既定パスは/usr/bin/chromium。別の場所では `CHROMIUM_PATH=/path/to/chromium npm run test:browser` を使います。

単体テスト6件で全40選択肢の採点、問題構造、冷水機のタッチ入力の1点判定、時間切れ、ランク境界、シャッフル、デバイスIDと画像の存在を検証します。ブラウザ検証では1366×768で全10問を完走し、4択、Eキーの無効化、二重回答防止、全40選択肢の復習、物理ボタンでの満点とタッチ入力の1点判定、混合採点、代替方法、タイマー、演出設定、全画面、画像欠損時の動作、JS例外と主要領域のはみ出しを確認します。テスト用HTTPは4175番で起動・終了し、結果JSONと画像は無視対象のwork/へ出力します。

学校の管理端末やGitHub Pages本番での確認、実機センサの性能評価は別途必要です。
