# SENSOR QUEST — 最適なセンサを選べ！

中学校技術科「計測・制御」「技術による問題解決」の導入教材です。身近な10場面で、**何を取得できるか、何は分からないか、条件に最も合う入力はどれか**を比較します。タイトル → 10問 → 解説 → 結果 → 問題別の復習まで遊べます。

Ver.2では既存の採点・シャッフル・復習を継承し、10問を授業用デバイスに限定して更新しました。[デバイスガイド](https://playa2021git.github.io/reinvent-device-guide/)の入力11＋AI3、出力5とIDが一致します。

## 起動とGitHub Pages

ビルド、CDN、データベース、ログイン、APIキーは不要。Python 3があればリポジトリ内で：

```sh
python3 -m http.server 4173
```

`http://localhost:4173/` を開きます。ES Modulesを使うため、ダブルクリックの `file://` ではなくローカルHTTPを使います。ゲームは静的ファイル配信だけで動き、外部サービスへ接続しません。PWAによる完全オフライン再読み込みは対象外です。

GitHub Pagesでは **Settings → Pages → Deploy from a branch → main / (root)** を選択します。公開URLは `https://playa2021git.github.io/sensor-quest/`。すべての資源を相対パスで読み込み、サブディレクトリに対応しています。今回の変更は専用ブランチのPRで提供し、mainへの自動マージやPages設定変更は行いません。

## 操作とルール

- **1366×768専用**。問題と5択はページを縦スクロールせず表示します。ほかの画面サイズへの最適化は対象外。
- マウス・タッチパッド、A〜Eキー、Tab＋Enterで回答。毎問の選択肢はシャッフルし、位置ではなくIDで採点します。
- 最適 `optimal` 2点、実現可能 `possible` 1点、不適切 `unsuitable` 0点、時間切れ `timeout` 0点。10問・20点満点。速さによる追加点なし。
- 最適でない選択も、取得情報・長所・限界・今回の理由を説明します。解説の比較タブで**5つすべて**を確認できます。比較タブは左右矢印・Home・Endキーにも対応。長い詳細だけ欄内スクロールを使い、重要な解説は16px以上を基準にしています。
- 1問60秒。設定で制限をなくせます。時間設定は次の問題から適用。ダイアログ中も時計は進みます。経過時間は `performance.now()` で計測し、問題内で現在時刻を使う設計は出題しません。
- 第6問前にステージ移行画面。ここでは時間を進めず、開始ボタンで次へ。STAGE 1はネイビー＋ゴールド、STAGE 2はスカイブルー＋ホワイト＋ネイビー＋イエロー。復習も該当ステージの配色になります。
- 正解の短い光と猫の喜ぶポーズ、結果の光・得点カウント、高得点の紙吹雪、満点の虹色の帯を追加。設定で全アニメーションをOFFにでき、OSの「動きを減らす」も優先します。音は初期ミュートで音量調整可能。全画面表示あり。
- 結果には4区分の数、ランク、振り返る問題、学びのメッセージを表示。全問復習、最適でなかった問題の復習、再挑戦ができます。
- ランク：S 18〜20 / A 15〜17 / B 11〜14 / C 7〜10 / D 0〜6点。点数は理解の参考情報であり、学習評価そのものではありません。

回答履歴は実行中のメモリにだけ保持し、再読み込みで消えます。設定のみlocalStorageへ保存。氏名・出席番号の収集、回答の外部送信、アクセス解析は行いません。保存不可でも動作します。カメラ・マイクの権限も要求せず、実際のAIモデルや電子部品をこのゲームが起動することはありません。

## 10問の構成

| STAGE 1：身近な技術を授業用デバイスで | STAGE 2：再発明・問題解決 |
|---|---|
| 1 学校の冷水機：意思を受け取るボタン | 6 猫の給水：種類と残量 |
| 2 駐車支援：分類と測距の違い | 7 忘れ物：確認操作と物の分類 |
| 3 夜間照明：明るさと動きのAND条件 | 8 二度寝：操作と在床の手がかり |
| 4 画面回転：重力から姿勢を推定 | 9 置き配の模型：検知・操作・本人認証を区別 |
| 5 騒音通知：音量と音の種類 | 10 異常音：学習した特徴とAIの限界 |

最適は条件と候補の範囲での判断です。採用方式不明の実在製品についてメーカーの方式を断定しません。第9問は教員管理下の動作模型に限定し、ボタンを本人認証や実用の盗難防止とは扱いません。詳細な判定根拠と要確認事項は [CONTENT_REVIEW.md](CONTENT_REVIEW.md) に記載しています。

```text

src/app.js            既存ゲームの画面・状態遷移・時計・操作

src/encyclopedia.js   使用可能な19種類の図鑑
src/assets.js         画像シートと個別差し替えの設定
src/style.css         既存の工房とVer.2のレイアウト・テーマ・演出
assets/*.png          生成した問題画像と猫の透過画像
```

問題データには従来の必須項目に加え、全choiceの `devices / information / strength / limitations` と、問題の `outputs / misconception / imageAlt` を持たせています。入力と出力は別フィールドです。新たな電子部品を追加する前に授業用ガイドの制限を確認してください。

10問固定の教材です。問題数を増やす場合はデータだけでなく20点満点、ランク、問題数の文言も見直してください。

画像生成機能を使用して、10場面と柔らかい表情の猫（通常・成功・説明・思考・結果など）を制作しました。主画像に従来の単純なSVGは使いません。画像はシートを共有して読み込み、CSSでセルを表示するため縦横比を維持します。個別画像へも差し替え可能です。配置ファイル、必要な構図、推奨ファイル名、フォールバックは [IMAGE_ASSETS.md](IMAGE_ASSETS.md) を参照してください。

## テスト

Node.js 20以上（開発用）で：

```sh
npm test
```

5件のテストで、10問・各5択・最適1つ・必須項目・PNGの存在、許可された14入力と5出力、全50選択肢の採点、時間切れ、全ランク境界、シャッフルを確認します。

ブラウザ検証はPython 3、Playwright、Chromiumが必要です。

```sh
npm ci
npm run test:browser
```

Chromiumの既定パスは `/usr/bin/chromium`。別の場所なら `CHROMIUM_PATH=/path/to/chromium npm run test:browser`。必要に応じて `npx playwright install chromium` で開発用ブラウザを用意します。テストはポート4175でローカルHTTPを起動・終了します。

検証内容（1366×768、Chromium）：

- サブディレクトリで配信し、10問をキー操作で完走。二重回答防止と混合採点11/20（B）を確認。
- 全50選択肢の情報・限界・理由を復習で確認。ステージ移行、6問目からの配色変更、復習時の配色も確認。
- 満点20/20（S）、結果の演出、全アニメーションOFF、OSのreduced-motion、全問最適時の復習一覧を確認。
- 仮想時計で30秒後の残り30秒、60秒超で時間切れ0点、時間制限なしを確認。
- 図鑑19種類、遊び方、全画面、再挑戦、画像欠損時の説明と操作継続を確認。
- JS例外、ページ・主要欄のはみ出しを検出。スクリーンショット・結果JSONは無視対象の `work/` に出力。

上記は開発環境で成功。現物Chromebook・学校の管理ポリシー下と、改修版のGitHub Pages本番公開後の確認は今後必要です。実機センサの精度・価格・AI認識率も未測定で、具体的な保証値は置いていません。
